# KoddiUD On Gothic

Original, unmodified Regular and Bold TTF files distributed by the Korea Disabled
People's Development Institute (KODDI). Downloaded 2026-11-12.

- Official distribution and usage terms: https://www.koddi.or.kr/ud/sub1_2
- Official TTF archive: https://www.koddi.or.kr/ud/download?bo_table=font_down&wr_id=26&no=0

The official usage guidance permits commercial and noncommercial design use.
Do not modify the font data, or sell/distribute the font itself for profit.
Keep these original font files and this provenance with the app distribution.

The app loads both weights locally with `expo-font`; it uses the system font if
loading fails. The UI typeface is separate from the original brand symbol.
