# App fonts

## Pretendard

The interface uses unmodified Pretendard v1.3.9 Regular, SemiBold and Bold,
bundled locally through `expo-font` for consistent Korean and Latin typography.
There is no runtime font CDN dependency. System fonts remain the load-error fallback.

- Source: https://github.com/orioncactus/pretendard/tree/v1.3.9/packages/pretendard/dist/public/static
- License: SIL Open Font License 1.1; see `pretendard-license.txt` in this directory.
- Downloaded: 2026-11-15. Keep the copyright and license with distribution.

## KoddiUD On Gothic (retained original assets)

Original, unmodified Regular and Bold TTF files distributed by the Korea Disabled
People's Development Institute (KODDI). Downloaded 2026-11-12.

- Official distribution and usage terms: https://www.koddi.or.kr/ud/sub1_2
- Official TTF archive: https://www.koddi.or.kr/ud/download?bo_table=font_down&wr_id=26&no=0

The official usage guidance permits commercial and noncommercial design use.
Do not modify the font data, or sell/distribute the font itself for profit.
Keep these original font files and this provenance with the app distribution.

These earlier typeface assets are retained. The UI typeface is separate from the
original brand symbol.
